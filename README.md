## Overview

DScore is a compact Progressive Web App for recording daily actions, assigning them simple priority categories, and tracking daily/weekly score trends.

Each action has a duration and a category based on the Eisenhower matrix: important/urgent, important/not urgent, not important/urgent, or not important/not urgent. The app calculates daily totals, category scores, weekly summaries, and simple charts.

## Features

* Daily action tracking
* Eisenhower-style scoring
* Decimal hour support
* Daily notes
* Weekly summaries
* Import/export JSON backups
* Offline-capable PWA
* Local device storage only

## Why Local-First?

DScore is intentionally built as a static local-first PWA. For a compact tracking utility, a backend, authentication system, and database would add unnecessary complexity.

The app runs as simple static files and stores data locally in the browser.

## Technology

HTML, CSS, Vanilla JavaScript, localStorage, Service Worker, and PWA manifest.

## Scope

This is a small utility project focused on quick use, offline access, and simple mobile-first interaction.
